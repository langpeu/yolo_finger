방금 녹화한 클립

  • 준비 시간이 끝나고 빨간 테두리가 뜨는 동안 동작하세요. 빨간 테두리 앞뒤 1초도 함께 저장돼서, 조금 일찍 시작하거나 늦게 끝나도 동작이 잘리지 않아요.
  • 단어마다 20개 이상을 권장해요. 위치·속도·손 높이를 조금씩 바꿔 가며 찍으면 좋아요.
  • (동작 없음)에는 가만히 있기, 손 내려놓기, 다른 손짓, 그리고 팔 동작은 같고 손 모양만 다른 동작을 넣어 주세요.
  • 손 인식이 50% 미만이면 손이 화면 밖에 걸린 거예요. 카메라에서 조금 떨어져 앉아 주세요.

손 인식 비율 (노란 선 = 최소 기준)

최근 인식

    녹화된 클립으로 단어마다 어떤 동작인지 보여줘요. 여러 클립 중 가장 전형적인 동작을 먼저 골라요. 거울처럼 보여서, 화면을 보며 그대로 따라 하면 돼요.
    손가락 색: 엄지 · 검지 · 중지 · 약지 · 새끼 · 옅은 선 = 손이 지나온 길
    불량 클립 = 손이 50% 미만으로 잡힌 클립이에요. 학습 전에 지우는 걸 권장해요. 하나씩 보고 지우려면 단어·클립 탭을 쓰세요.
    
      
    
    
    

    
    
    
      
    공유 단어 50개에서 추가
    
      
    눌러서 추가해요. ID·이름·녹화 길이가 정해져 있어서 여러 사람 데이터를 합칠 때 같은 단어로 모여요. ✓ = 이미 추가한 단어.
    
      
    
      
    개인 단어 직접 추가
    
      
    50개 목록에 없는 단어예요. ID는 공유 단어 ID나 이미 있는 단어와 겹치면 안 돼요. 데이터 공유 때 이 이름 그대로 함께 보내져요.
    
      
    
        
        
        
        
      
    
      
    단어 목록
    
      
    
      
    
        
    
        
    
          
          
          
          삭제한 클립은 바로 지워지고 되돌릴 수 없어요.
        
    
        
    
          
    
          
    
        
    
      
    

      
    전체 초기화
    
      
    녹화한 클립(합친 클립 포함), 단어 목록, 학습한 모델, 학습 기록, 지운 클립·뺀 ID 목록을 모두 지우고 처음부터 시작해요. 임시 ID와 설정은 그대로 남아요. 바로 지워지고 되돌릴 수 없어요.
    
      
    
        
        
      
    
    
    

    
    
    
      
    
        
        
        실명·이메일은 쓰지 마세요. 내보내는 클립에 이 ID가 붙어요.
      
    

      
    내보내기
    
      
    단어·클립에 있는 단어 전부(공유 단어, 개인 단어, 동작 없음)의 클립을 zip 하나로 받아요. 합쳐 둔 다른 사람 클립도 원래 ID 그대로 들어가요. 손 인식 50% 미만인 단어 클립은 빠져요.
    
      
    
      
      

      
    합치기
    
      
    받은 zip 파일을 한 폴더에 모아 두고 그 폴더를 고르세요. 폴더 안의 zip을 모두 풀어 내 단어·클립 목록에 더해요. 이미 있는 클립은 건너뛰어요.
    
      
    
        
        
        
      
    
      
    

      
    합친 데이터
    
      
    
      
    학습 탭에서 학습을 시작하면 내 클립과 합친 클립 전체로 학습해요. 어떤 사람이 빼 달라고 하면 그 ID의 클립을 지우세요. 바로 지워지고, 앞으로 어떤 zip에서도 그 ID의 클립은 합치지 않아요.
