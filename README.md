# 수어 학습기 by Langpeu

웹캠으로 한국 수어 단어를 직접 녹화하고, 학습시키고, 실시간으로 인식하는 윈도우용 프로그램이에요.
모든 조작은 브라우저 웹페이지에서 해요.

## 주요 기능

- **녹화**: 단어를 고르고 1회 녹화 또는 자동 연속 녹화. 방금 녹화한 클립을 바로 확인하고 지울 수 있어요.
- **실시간 인식**: 인식된 단어, 단어별 확률, 손 인식 비율, 최근 인식 기록을 보여줘요.
- **학습**: 버튼 한 번으로 학습. 따로 떼어 둔 클립으로 단어별 정확도와 헷갈림 표를 보여줘요.
- **단어·클립 관리**: 단어 추가·이름 변경·녹화 길이 설정, 클립 재생(관절 움직임), 불량 클립 정리.
- **설정 / 학습 기록**: 인식 기준, 웹캠 해상도·FPS 등 설정과 학습할 때마다의 정확도 기록.

## 인식 방식

1. **YOLO11 Pose** (GPU): 사람과 몸 관절을 찾고, 카메라에 **가장 가까운 사람**을 화자로 골라요. 다른 사람은 회색으로 가리고 무시해요.
2. **MediaPipe Hand Landmarker** (CPU): 화자의 손가락 관절 21개 × 양손.
3. 프레임마다 팔·손 위치, **손가락 모양**(손목 기준 좌표, 관절 각도), **움직임**(속도·방향)을 특징으로 만들어요.
4. **GRU 분류 모델**(PyTorch)이 최근 몇 초의 특징을 보고 단어를 판정해요.

학습할 때는 속도를 바꾼 복사본, 정지 상태, 손 모양만 바꾼 반대 예시, 움직임만 없앤 반대 예시를 자동으로 만들어서
팔 위치나 손 모양 하나만 보고 판정하지 않도록 해요.

## 필요한 것

- Windows 10 / 11
- 웹캠 (예: Logitech C920, 노트북 내장 웹캠)
- NVIDIA 그래픽카드 권장 (없으면 CPU로 동작, 느림)
- 처음 설치할 때 인터넷 연결

## 설치와 실행

파워쉘 이나 터미널에서 아래처럼 입력. (git 은 설치되어 있어야 합니다.)
```
PS C:\Windows\System32> cd c:\
PS C:\> git clone https://github.com/langpeu/yolo_finger
PS C:\> cd C:\yolo_finger\
PS C:\yolo_finger> .\1_web.bat
```

1. 이 저장소를 내려받아 **`C:\yolo_finger`처럼 C 드라이브 바로 아래**에 두세요.
   `문서`, `바탕 화면` 폴더는 윈도우 보안(제어된 폴더 액세스)이 설치를 막을 수 있어요.
2. **`1_web.bat`** 을 더블클릭하세요.
   - 처음 실행하면 파이썬 3.12, PyTorch(그래픽카드에 맞는 버전), YOLO, MediaPipe가 자동으로 설치돼요. (10~20분)
   - 설치가 끝나면 브라우저에 `http://127.0.0.1:8000` 이 열려요.
3. 끝낼 때는 웹페이지 오른쪽 위 **종료** 버튼을 누르세요. 검은 창도 함께 닫혀요.

### 종료 규칙 (바꾸지 않아요)

종료 방식은 아래로 정해져 있고, 앞으로 고칠 때도 바꾸지 않아요.

1. 웹페이지 **종료** 버튼을 누르면 서버가 웹캠을 놓고 종료 코드 99로 꺼지고, `1_web.bat` 검은 창도 함께 닫혀요.
2. 웹페이지는 탭을 스스로 닫지 않아요. "수어 학습기를 종료했어요" 화면이 그대로 남아요.
3. 수어 학습기 탭이 여러 개 열려 있으면 모두 같은 끝 화면으로 바뀌어요.
4. 탭을 잠그는 기능("다른 탭에서 열려 있어요" 같은 것)은 넣지 않아요.

설치가 꼬였을 때는 `0_setup.bat` 으로 다시 설치할 수 있어요.

## 사용 순서

1. **단어·클립** 탭에서 단어를 추가해요. **공유 단어 50개**에서 눌러 고르면 ID·이름·녹화 길이가 정해진 대로 들어가요.
   목록에 없는 단어는 **개인 단어**로 직접 추가해요 (ID는 공유 단어 ID나 이미 있는 단어와 겹치면 안 돼요).
2. **녹화** 탭에서 단어마다 20개 이상 녹화해요. **(동작 없음)** 에는 가만히 있기, 손 내려놓기, 손만 들어 올리기처럼
   헷갈리기 쉬운 평소 동작을 녹화해요.
3. **학습** 탭에서 학습 시작.
4. **실시간 인식** 탭에서 확인해요.

## 데이터 공유 (여러 사람 클립 합치기)

여러 사람이 녹화한 클립을 모아 함께 학습할 수 있어요. 클립은 영상이 아니라 관절 좌표 데이터예요.

1. **내보내기**: **데이터 공유** 탭에서 동의에 체크하고 **zip 내려받기**를 눌러요.
   단어·클립에 있는 단어 전부(공유 단어 50개 중 추가한 것, 개인 단어, 동작 없음)의 클립이 `signdata_<임시ID>_<날짜>.zip` 하나로 받아져요.
   합쳐 둔 다른 사람 클립도 원래 임시 ID를 단 채로 함께 들어가요.
2. 받은 zip을 모을 사람에게 보내요 (예: 슬랙).
3. **합치기**: zip 파일을 한 폴더에 모아 두고 **폴더 선택해서 합치기**로 그 폴더를 골라요.
   zip 안의 클립이 내 단어·클립 목록에 더해져요. 클립 내용으로 중복을 확인해서, 같은 zip을 다시 합치거나
   내 클립이 다른 사람 zip에 섞여 돌아와도 겹치지 않아요.
4. **학습** 탭에서 학습을 시작하면 내 클립과 합친 클립 전체로 학습해요. 결과에 기여자 수가 나와요.

- 임시 ID는 처음 실행할 때 무작위로 만들어져요(`data/contributor.json`). 실명이나 이메일은 쓰지 마세요.
- 어떤 사람이 빼 달라고 하면 **합친 데이터** 표에서 그 ID의 클립을 지울 수 있어요. 그 뒤로는 어떤 zip에서도 그 ID의 클립을 합치지 않아요 (**다시 받기**로 되돌릴 수 있어요).
- 내가 지운 다른 사람 클립은 `data/deleted_clips.json` 에 기억돼서, 다른 zip에 들어 있어도 다시 합쳐지지 않아요. **지운 클립 목록 비우기**로 초기화할 수 있어요.
- 손 인식 50% 미만인 단어 클립은 내보내지 않아요 ((동작 없음)은 모두 보내요).
- 공유 단어는 정해진 ID로 모여요. 개인 단어는 만든 사람과 원래 ID가 같을 때만 같은 단어로 모여요.
  다른 사람의 개인 단어가 내 단어와 ID만 같으면 들어온 순서대로 `ID_01`, `ID_02` 로 따로 추가돼요 (이름 뒤에 만든 사람 ID가 붙어요).

## 전체 초기화

**단어·클립** 탭 맨 아래 **전체 초기화**로 데이터셋을 모두 지우고 새로 시작할 수 있어요.
확인 칸에 `초기화` 를 입력해야 버튼이 눌려요.

- 지우는 것: 모든 클립(합친 클립 포함), 단어 목록(처음 기본값으로), 학습한 모델, 학습 기록, 지운 클립·뺀 ID 목록
- 남기는 것: 임시 ID, 설정
- 바로 지워지고 되돌릴 수 없어요. 필요하면 먼저 **데이터 공유** 탭에서 zip으로 내보내 두세요.

## 폴더 구조

```
yolo_finger/
├─ 1_web.bat            실행
├─ 0_setup.bat          파이썬 환경 설치·복구
├─ requirements.txt     설치할 패키지 (PyTorch는 그래픽카드에 맞게 따로 설치)
├─ CLAUDE.md            코드를 고칠 때 지킬 규칙 (종료 규칙 등)
├─ app/                 파이썬 코드
│  ├─ web_app.py        웹 서버, 카메라, 녹화·인식
│  ├─ sign_common.py    폴더·설정, 특징 계산, 화자 추적, 모델, 실시간 인식
│  ├─ sign_train.py     학습
│  ├─ sign_share.py     데이터 공유 (내보내기·합치기)
│  ├─ vocab.json        공유 단어 50개 목록
│  └─ setup_helper.py   설치 도우미 (그래픽카드 확인)
├─ web/                 웹페이지 (index.html, 로고)
├─ scripts/             보조 bat (_env.bat, _setup.bat) — 직접 실행하지 않아요
├─ models/              YOLO·MediaPipe 모델 파일 (자동 다운로드, git 제외)
├─ data/                녹화 클립·학습 모델·단어 목록·설정·학습 기록 (git 제외)
└─ env_<컴퓨터이름>/    이 컴퓨터용 파이썬 환경 (git 제외)
```

`data/`, `models/`, `env_*/` 는 `.gitignore` 로 저장소에서 빠져 있어요.
다른 컴퓨터로 옮길 때는 `env_*/` 폴더만 빼고 복사하면, 그 컴퓨터에서 `1_web.bat` 이 환경을 새로 설치해요.
